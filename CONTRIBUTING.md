# Правила проєкту

- Дотримуйтеся вимог завдання та стилю сусідніх модулів. Зберігайте EventEmitter і захисні перевірки.
- Обирайте прості рішення без зайвих залежностей і обгорток.
- Додавайте функції виводу разом із відповідними командами.
- Зберігайте корисні коментарі й тести; перевіряйте змінену поведінку та її важливі межі.
- Перед завершенням CLI запустіть усі команди з package.json і звірте README з їхньою поведінкою.
- У README залишайте встановлення, команди, приклади та суттєві особливості застосунку.
- Робіть логічні коміти. У PR коротко описуйте задачу та виконані перевірки.
- Перед публікацією перечитайте diff і приберіть випадкові зміни.
