# File Organizer CLI

Застосунок для аналізу директорій, пошуку дублікатів, сортування копій і видалення старих файлів.

## Встановлення

Потрібні Node.js 22 або новіший і npm. Сторонніх залежностей немає.

```sh
git clone https://github.com/Zexler/file-organizer.git
cd file-organizer
npm ci
```

Команди запускаються з кореня проєкту. Шляхи з пробілами беріть у лапки.

## Команди

### Статистика

```sh
node file-organizer.js scan "./example files"
npm run scan -- "./example files"
```

Рекурсивно рахує файли та їхній загальний розмір, групує за розширенням, показує вікові групи, три найбільші файли й найстаріший файл.

Вік визначається за датою зміни (`mtime`). Групи «останні 7 днів» і «останні 30 днів» перетинаються та включають свої межі. «Старше 90 днів» означає строго понад 90 днів. Майбутні дати до останніх 7/30 днів не входять.

### Дублікати

```sh
node file-organizer.js duplicates ./downloads
npm run duplicates -- ./downloads
```

Порівнює SHA-256 вмісту незалежно від назви файлу. Звіт містить хеш, повні шляхи копій та зайняте зайвими копіями місце: `розмір × (кількість копій − 1)`. Команда нічого не видаляє. Хешування виконується потоково.

### Сортування копій

```sh
node file-organizer.js organize ./downloads --output ./sorted
npm run organize -- ./downloads --output ./sorted
```

Створює всі шість категорій, копіює до них файли з вкладених папок і показує підсумок. Оригінали зберігаються; вкладена структура всередині категорій не відтворюється.

| Категорія | Розширення |
| --- | --- |
| Documents | `.pdf .docx .doc .txt .md .xlsx .pptx` |
| Images | `.png .jpg .jpeg .gif .svg .webp .bmp` |
| Archives | `.zip .rar .tar .gz .7z` |
| Code | `.js .py .java .cpp .html .css .json` |
| Videos | `.mp4 .avi .mkv .mov .webm` |
| Other | Решта, зокрема файли без розширення |

Регістр розширення не враховується. Якщо назва зайнята, створюється `file(1).pdf`, потім `file(2).pdf`. Повторний запуск додає копії. Файли менші за 10 MB копіюються через `copyFile`, від 10 MB — потоками; тут 1 MB = 1 048 576 байтів.

Джерело й результат не можуть збігатися або бути вкладеними одне в одне. Посилання категорій за межі результату відхиляються.

### Очищення

```sh
node file-organizer.js cleanup ./temporary --older-than 30
npm run cleanup -- ./temporary --older-than 30
```

Без `--confirm` показує лише список кандидатів із розмірами, датами й віком та загальний обсяг. Для видалення:

```sh
node file-organizer.js cleanup ./temporary --older-than 30 --confirm
npm run cleanup -- ./temporary --older-than 30 --confirm
```

`--older-than` — обов'язкове невід'ємне скінченне число днів; допускається `1.5`. Поріг строгий: файл віком рівно 30 днів не видаляється при значенні `30`. Значення `0` охоплює файли, змінені раніше моменту запуску.

З `--confirm` після списку й попередження файли видаляються остаточно, без кошика та додаткового запиту. Виводиться кількість видалених файлів і звільнений обсяг. Порожні папки залишаються. Якщо після перегляду кандидат змінив тип, розмір або дату, очищення зупиняється.

## Інші параметри та поведінка

- `node file-organizer.js --help` — довідка; `--version` — версія.
- `npm test` — запуск тестів.
- Розміри виводяться у B, KB, MB, GB або TB. Прогрес показується в інтерактивному терміналі.
- Символічні посилання та junction усередині дерева пропускаються.
- Код завершення: `0` — успіх, `1` — помилка. Пояснення помилки виводиться у stderr.
- Після помилки робота зупиняється. Уже скопійовані або видалені файли не відновлюються автоматично. Застосунок не блокує паралельних змін директорії.

## Структура

`file-organizer.js` — точка входу. У `lib/` розміщені `scanner.js`, `duplicates.js`, `organizer.js` і `cleanup.js` — класи команд з подіями EventEmitter; `files.js` — обхід директорій, `arguments.js` — аргументи, `display.js` — консольний вивід. Тести знаходяться в `test/`.
